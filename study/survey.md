# Pairwise layout survey draft

Show the source design, target format, and two anonymized target layouts. Randomize left/right placement.

For each pair, ask:

1. Which target better preserves the source's visual hierarchy?
2. Which target guides your attention in a way most similar to the source?
3. Which target better preserves spacing and grouping relationships?
4. Which target feels more like the same design overall?
5. Did either target crop, hide, or make essential content unreadable? If yes, describe it.

Capture confidence on a five-point scale and an optional explanation. Include attention checks and record target dimensions, anonymized method IDs, solver version, fixture version, and presentation order.
